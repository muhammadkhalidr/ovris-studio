OVRIS Studio

A private, read-only analytics tool for the OVRIS YouTube channel.

What it does

OVRIS Studio reads performance data for the OVRIS channel from YouTube and shows it on a dashboard that runs on the channel owner's own computer. The owner uses it to see how videos perform, such as where viewers stop watching, and to make better videos.

Who can use it

Only the owner of the OVRIS channel uses this tool. It is not offered to the public, and there is no sign-up.

Why it asks for access

The owner signs in with Google to allow read-only access to the channel's own data. The tool requests these two permissions:

  • View YouTube Analytics reports, for retention, watch time, traffic sources, impressions and click-through rate.
  • View your YouTube account, for the channel's video list and current view, like and comment counts.

What it cannot do

The tool cannot upload, edit or delete videos, and it cannot change channel settings.

Privacy Policy

OVRIS Studio uses YouTube API Services. By using OVRIS Studio, you agree to be bound by the YouTube Terms of Service.
