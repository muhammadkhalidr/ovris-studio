Privacy Policy

OVRIS Studio. Last updated November 5, 2026.

OVRIS Studio is a private tool used only by the owner of the OVRIS YouTube channel. It is not offered to the public.

YouTube API Services

OVRIS Studio uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool accesses

With the channel owner's consent, the tool reads this data for the owner's own channel:

  • Analytics reports: views, watch time, audience retention, subscribers gained, traffic sources and search terms, and audience totals by country, device and age group.
  • Reach reports: thumbnail impressions and click-through rate.
  • Channel and video details: titles, publish dates, and view, like and comment counts.

Access is read-only. These reports are statistics about the channel. The tool does not request information that identifies individual viewers.

How the data is used and shared

  • The data is shown on a dashboard on the owner's computer and is used to improve future videos.
  • The owner uses an AI assistant, Claude Code by Anthropic, to analyze the data, so parts of it are sent to Anthropic under the owner's account. See Anthropic's privacy policy.
  • The data is not sold, not used for advertising, and not shared with anyone else.
  • The use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Where the data is stored

The authorization token and the downloaded reports are stored only on the owner's computer. OVRIS Studio has no server of its own. The tool checks at least every 30 days that its access is still authorized, and it refreshes or deletes stored data as required by the YouTube API Services Developer Policies.

Cookies and third parties

This website and the tool set no cookies and show no advertising or third-party content. The company hosting this website may keep standard server logs.

Revoking access

Access can be revoked at any time on the Google security settings page. After that, the tool can no longer read any data, and the owner deletes the stored reports from their computer.

Contact

For questions or complaints about these practices, please open an issue on GitHub.
